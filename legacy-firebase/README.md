# Conecta — implementação antiga Firebase (arquivada)

Esta pasta contém **somente o código legado**, mantido como referência histórica da rede original.

A aplicação ativa é **Next.js + TypeScript + Supabase**, na pasta `web/`.
Configure a Vercel com `Root Directory = web` e Framework `Next.js`.
Não servir nenhum HTML desta pasta; todos os fluxos de login em produção devem usar Supabase Auth.

Os arquivos foram movidos sem modificar seu conteúdo. Dados, usuários e mídias do Firebase não foram migrados nem excluídos.
